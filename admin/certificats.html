Certificats PDF

Vérifier les paiements, clôturer l’activité, puis publier les certificats dans l’espace étudiant.

Vérification de la session administrateur...

1. Activité & participants

Seuls les certificats demandés avec un paiement vérifié par l’administration sont publiables, après la fin de l’activité. Les certificats gratuits validés par le serveur sont également acceptés. Un simple dépôt de preuve ne suffit pas.

2. Modèle sans nom (PNG ou JPEG)

Importez votre exemple de certificat avec la zone du nom vide. Le titre, la date, les signatures et le logo doivent déjà être dans l’image. Cliquez sur l’aperçu pour placer le nom. Le modèle reste local à cet onglet ; les PDF publiés sont conservés sur le serveur.

Les doublons transférés sont regroupés. Aucun PDF existant n’est écrasé. Un PDF téléversé manuellement doit déjà porter le bon nom. L’étudiant doit se connecter avec l’email de son inscription pour le télécharger.
