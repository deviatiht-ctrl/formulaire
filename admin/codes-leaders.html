En tête du classement global

Le classement compte toutes les inscriptions d’origine avec un code : paiement en attente, refusé, gratuit ou vérifié, y compris les inscriptions annulées. Les copies techniques créées lors d’un transfert ne sont pas recomptées. Une personne inscrite à plusieurs activités peut avoir plusieurs utilisations.

Aucun historique n’est effacé. Les leaders désactivés et les anciens codes restent visibles. Le classement public des certificats payés reste distinct de ce rapport administratif.
